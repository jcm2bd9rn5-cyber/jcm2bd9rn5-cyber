### Behind the build

- **きっかけ：** 自分の筋トレ経験から、前回記録をすぐ確認でき、友人との競争も継続の力になるアプリを作りたいと考えました。
- **担当範囲：** UI設計、認証、データ保存、課金、ストア公開、公開後の改善まで一貫して担当しています。
- **実装の工夫：** Androidの休憩通知は、正確な時刻指定で予約できない場合に別方式で再試行。終了済みタイマーの通知予約も防いでいます。
